# PHP Practice Labs 🐘

Welcome to my **PHP Practice** repository! This repository contains a collection of scripts and mini-projects I created while learning and practicing core PHP development.

## 📂 Repository Contents

* **`Basic_php.php` & Lab Tasks**: Contains fundamental PHP concepts including:
  * Variables, Data Types, and Constants
  * String Manipulation
  * Arrays and Loops
  * Functions
* **`CRUD operation/`**: A fully functional CRUD application demonstrating database integration with PHP and MySQL. It includes:
  * **C**reate: Inserting new records into a database (`insert.php`).
  * **R**ead: Fetching and displaying records from the database (`read.php`).
  * **U**pdate: Modifying existing records (`edit.php`).
  * **D**elete: Removing records from the database (`delete.php`).
  * **File Uploads**: Handling image/file uploads to the server (`file-upload.php`).

## 🚀 Purpose

The main goal of this repository is to document my journey in learning server-side programming, database management, and handling user inputs securely using PHP.

* **PHP** 
* **MySQL** 
* **HTML/CSS**
